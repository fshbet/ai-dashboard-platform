# AI Dashboard Generation Platform

> Drop in a CSV, XLSX, or JSON file and get an interactive, audience-segmented dashboard —
> generated by a five-node AI pipeline that emits specifications, never rendered output.

**Status:** Working prototype · no test suite yet
**Stack:** Next.js 14 · TailwindCSS · ECharts · Node.js/Express · TypeScript · n8n · SQLite

---

## What it does

```
Upload → Backend API → n8n Workflow → AI Nodes (×5) → Dashboard JSON Spec → Frontend Renderer
```

The architectural commitment worth noting: **the AI generates specifications only.** It never
produces chart images, HTML, or rendering code. The frontend owns all rendering, filtering,
and interaction, driven by a validated JSON spec. That keeps the AI's output small, testable,
and impossible to break the UI with — a malformed spec fails validation instead of shipping a
broken dashboard.

## Stack

| Layer | Technology |
|---|---|
| Frontend | Next.js 14, TailwindCSS, ECharts |
| Backend | Node.js, Express, TypeScript |

| Storage | SQLite (better-sqlite3) |
| File parsing | PapaParse (CSV), xlsx (Excel) |

## Getting started

```bash
cp .env.example .env          # add your OpenRouter API key
docker compose up --build
```

Or run the two halves directly:

```bash
cd backend && npm install && npm run dev     # Express API
cd app     && npm install && npm run dev     # Next.js frontend
```

Import `n8n/workflows/dashboard-gen.json` into your n8n instance and point the backend at it.
See [`INSTALL.md`](INSTALL.md) for the full walkthrough.

## Layout

```
backend/src/
  index.ts          Express server entry
  routes/           upload, dashboard, export
  services/         fileParser, n8nOrchestrator, validator
  models/           SQLite database and queries
  middleware/       Multer file upload
  types/            TypeScript interfaces

app/src/            Next.js 14 frontend
  app/              Upload page, dashboard page
  components/       KPIGrid, ChartRenderer, AudienceTabs, GlobalFilters, Sidebar, ExportButton
  lib/              API client, ECharts adapters, types
  store/            Zustand state management

n8n/workflows/      dashboard-gen.json — import into n8n
ai-prompts/         Prompt templates for the five AI nodes
schemas/            Dashboard spec schemas
```

`schemas/` and `ai-prompts/` are the contract between the AI pipeline and the renderer —
change a schema and both sides must follow.

  design leans on it.
- Requires an OpenRouter API key and a running n8n instance; there is no offline mode.
